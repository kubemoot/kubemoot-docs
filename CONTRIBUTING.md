# Contributing to the docs site

Documentation for each component lives in that component's repo. To change the
operator, agent runtime, reference, or kmctl pages, edit `docs/` in
[kubemoot/kubemoot](https://github.com/kubemoot/kubemoot). To change the site shell,
landing page, or cross-cutting chapters, edit this repo. See the organization's
[contributing guide](https://github.com/kubemoot/.github/blob/main/CONTRIBUTING.md) for
the general process.
