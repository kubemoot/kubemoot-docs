Kubemoot follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html),
version 2.1. It applies in every project space: GitHub issues, pull requests, and
Discussions, and any other place where someone represents the project in public.

The full text lives in one place, the
[`CODE_OF_CONDUCT.md`](https://github.com/kubemoot/.github/blob/main/CODE_OF_CONDUCT.md)
file in the organization's `.github` repository. GitHub shows it on every repository in
the organization, so it is not copied into each one.

## The short version

- Be respectful of differing opinions, viewpoints, and experience.
- Give and accept constructive feedback gracefully.
- Take responsibility for mistakes and learn from them.
- Focus on what is best for the community, not only for you.

Harassment, trolling, insulting comments, and publishing others' private information
are not acceptable.

## Reporting a concern

Write to [conduct@kubemoot.org](mailto:conduct@kubemoot.org). Reports are reviewed and
investigated promptly and fairly, and the reporter's privacy and security are
respected. The enforcement guidelines (correction, warning, temporary ban, permanent
ban) are in the full text.
