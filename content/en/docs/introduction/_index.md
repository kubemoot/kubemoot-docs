Install Kubemoot and get a crew answering questions.

New to Kubernetes, or unsure how your machines connect to the machine that runs the
model? Start with [How the Pieces Fit Together](how-the-pieces-fit-together/).

Kubemoot's release images are `amd64` only today, so the cluster needs `amd64` nodes
(Intel and AMD PCs). They do not run on `arm64` nodes such as a Raspberry Pi or Apple
silicon; see [Install the Operator](installation/#prerequisites) and the
[Roadmap](roadmap/#images-for-arm64).
